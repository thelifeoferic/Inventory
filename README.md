# Wren inventory — flat GitHub upload

Select every file INSIDE this folder and drop those files into the GitHub repository root. Do not drag the folder itself or the ZIP. There are no subfolders, and every file is smaller than 500 KB.

This contains the complete source and all assets from The-Nest-GitHub, packed into numbered JSON parts. Keep every part. npm run build, npm run dev, and npm test automatically restore the original directories and all 317 assets. Do not upload the files generated by running those commands locally.

Vercel uses npm run build. Existing Supabase service and allowed-origin configuration remain unchanged. No live database records, account credentials, or private keys are included. This upload does not deploy the Supabase backend or delete old GitHub files.

The ordinary readable source package is still available separately as The-Nest-GitHub.zip. The JSON parts here are a workaround for folder upload failures; source changes should be made in the readable source project and repackaged, since restoration replaces generated source files.
